# Duomenys

Čia įdėkite `train.csv` iš Kaggle konkurso
[Jigsaw Toxic Comment Classification Challenge](https://www.kaggle.com/c/jigsaw-toxic-comment-classification-challenge/data).

1. Prisijunkite prie Kaggle ir konkurso puslapyje paspauskite **Join / I understand and accept**.
2. Atsisiųskite `train.csv.zip`, išarchyvuokite ir įdėkite `train.csv` į šį katalogą.

Failas turi stulpelius: `id, comment_text, toxic, severe_toxic, obscene, threat, insult, identity_hate`
(~159 tūkst. Vikipedijos diskusijų komentarų, anotuotų žmonių).
